# Личная история — Remotion

Вертикальный монтаж 1080×1920, 30 fps, **32,2 секунды** (966 кадров).

Из непрерывного исходника на 82 секунды выбраны восемь фрагментов: хук, контекст, основная история и финал. Длинные отступления и паузы между выбранными фразами удалены. Добавлены крупные субтитры с подсветкой произносимого слова и четыре анимированных акцента: «Новые краски», «Моя компания», «Верхушка айсберга», «Всё на свои места».

## Посмотреть результат

Отдельный файл `preview.html` содержит весь ролик, шрифт и Remotion Player. Скачайте его и откройте в современном Chrome, затем нажмите кнопку воспроизведения. Интернет для просмотра не нужен.

В архив проекта этот большой HTML-файл не дублируется. Его можно заново собрать командой `npm run preview:build`; результат появится в `out/preview.html`. Если браузер ограничивает открытие локальных HTML, используйте `npm run preview:serve` и адрес, напечатанный сервером.

## Открыть проект в Remotion Studio

Из папки проекта, с Node.js 24 или совместимой поддерживаемой версией:

```sh
npm ci
npm run dev
```

Выберите композицию **Reel**. Композиция **Source** показывает подготовленный полный исходник для сравнения.

## Где редактировать

- `src/Composition.tsx` — восемь отдельных элементов таймлайна, обрезки, исходное видео и массивы субтитров. Субтитры каждого фрагмента находятся внутри его группы и используют исходные временные метки.
- `src/Graphics.tsx` — оформление субтитров, цветовое выделение слов, иконки и анимация.
- `edit.json` — монтажные точки и длительность.
- `source-captions.json` — расшифровка полного исходника, включая удалённые части.
- `captions.json` — субтитры выбранных фрагментов с временными метками готового монтажа.
- `public/source.mp4` — исходное изображение без повторного кодирования; аудио перекодировано в AAC с мягким подавлением шума, фильтром ветра и нормализацией громкости.
- `public/captions-bold.woff2` — локальный Manrope ExtraBold, лицензия в `public/FONT-LICENSE.txt`.

Речь расшифрована локально моделью Whisper Small. Субтитры автоматические; названия и неразборчивые слова можно исправить непосредственно в Studio или в коде. Для изменения длительности обновите регистрацию Reel в `src/Composition.tsx`, параметры Player в `preview.tsx` и соответствующие подписи в `build-preview.mjs`.

## Проверка

```sh
npm run lint
npm run preview:build
```

Проверены TypeScript, ESLint, кадры композиции, воспроизведение HTML-предпросмотра, переходы и перемотка по всем восьми фрагментам. Полный MP4 не экспортировался: выбран предпросмотр и редактируемый проект.
